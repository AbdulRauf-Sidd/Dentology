# Dentology: Dental Management System

Welcome to Dentology, a comprehensive web application designed for dentists to manage their patients' histories efficiently. This system allows dentists to store and retrieve scans of individual teeth, maintain medical histories, and search for patient records with ease.

## Features

- **Patient Management**: Store and manage detailed patient records, including personal information and medical history.
- **Teeth Scans**: Upload and organize scans of individual teeth for each patient.
- **Search Functionality**: Efficiently search for patient records using various criteria.
- **User-Friendly Interface**: Intuitive design for easy navigation and use.
- **Secure Access**: Role-based access control to ensure data privacy and security.

## Technologies Used

- **Django**: The web framework used for building the application.
- **SQLite**: Database for storing patient records and dental scans.
- **Python**: Programming language used for backend logic.
- **HTML/CSS/JavaScript**: For frontend design and interactivity.
- **Bootstrap**: For responsive and modern UI design.
